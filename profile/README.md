# eSAMS

**Cloud school management for basic schools in West Africa.**

eSAMS brings student records, attendance, assessment and terminal report cards into one secure platform, built around how schools in Ghana actually run: continuous assessment and exams, class positions, head teacher remarks, and report cards parents can trust.

### What eSAMS does
- **Students, guardians and staff** — admissions, enrolment, imports from spreadsheets
- **Attendance** — daily registers by session, with term totals on the report card
- **Assessment** — class scores and exams, weighted to each school's scheme
- **Results** — grades, positions and averages, calculated exactly
- **Report cards** — school-branded PDFs, reviewed by the head, then released to parents
- **Built for the region** — multi-country by design, English and French

### Status
Launching with pilot schools in Ghana in **January 2027**.
